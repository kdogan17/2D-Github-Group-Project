# 2D Github Group Project
A 2D 32x32px dungeon crawler where player fights through waves of enemies with the goal of defeating the boss. Warning: plenty of toast, cook or get cooked in this game. 

Group Members: 
Khalia Dogan 
Azzy Axtell 
Lily Hall 
Reynaldo Gregory 
Charles Gale

When you get the repository to access game, clone this repository onto GitHub Desktop and put it in a folder so it downloads onto your machine. Then on Unity Hub, select "Add project from disk" and select said GitHub folder then you should be good to go!

# Important Note!
When preparing to work on project, be sure to fetch and pull from origin so you get all the files updated (same when you update things as well so everyone gets stuff up to date), and make sure to work on your own scene otherwise the game will break! There will be a master scene for main game and individual folders where everyone can work on scripts/assets and then will later be put into the master scene.
